Implementation defaults (not extra requirements): reference design/file-explorer/01-familiar-grid.html and design/system.md; other artboards remain alternatives. Linux is the existing setup target. Favorites are explicitly session-only (no configuration writes); support adding/removing current folder. Trash reads the freedesktop home trash only and labels that scope, without restore/delete/empty or automatic traversal of other volumes' trash. Search is local filename matching, not recursive/content search. Lossy labels must retain original filesystem paths for navigation. Directory loading runs off the UI thread with a generation guard; failed or stale loads must not corrupt the current location/history/selection. No new dependencies expected. No file contents opened except system location configuration, mount tables and trash metadata required for discovery; tests use isolated synthetic directories. Never read/edit/source protected .envrc or credentials; direnv remains user-managed. Preserve existing untracked design/ and .envrc.
